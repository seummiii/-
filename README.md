# 피자가게 매출 분석

본 프로젝트는 피자가게 주문 데이터를 활용하여
시간대·요일·메뉴 구성에 다른 매출 패턴을 분석하고,
운영 및 마케팅 관점에서 실행 가능한 인사이트를 도출하는 것을 목표로 합니다.

## 주요 분석 내용
- 월별 매출 추이 및 계절성 분석
- 요일·시간대별 주문 피크 분석
- 메뉴 카테고리 및 사이즈별 매출 기여도 분석
- 매출 기준 상위 메뉴(Top 10) 분석

## 핵심 인사이트
- 금요일에 주문 수와 매출이 가장 집중됨
- 점심/저녁 시간대에 뚜렷한 주문 피크 존재
- 소수의 핵심 카테고리와 사이즈가 매출을 주도
- 비수기 요일에 대한 타겟 프로모션 필요성 확인

## 파일 구성
`피자가게 매출 최적화를 위한 데이터 분석 결론.ipynb`: 전체 분석 과정이 담긴 Jupyter Notebook
- `orders.csv`: 분석에 사용된 원본 주문 데이터
- `pizzas.csv`: 피자 메뉴 및 가격 정보
- `pizza_types.csv`: 피자 카테고리 및 재료 정보
